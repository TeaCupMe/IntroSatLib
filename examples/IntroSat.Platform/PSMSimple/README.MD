# Пример работы с платой питания PSM

Скетч опрашивает плату питания **pl_psm 1.x** по UART через драйвер [IntroSatLib](https://github.com/Obu-IntroSat/IntroSatLib).

## Подключение

UART **115200 8N1**:

| Хост (этот скетч) | PSM |
|---|---|
| TX (`Serial1`) | PA10 (`USART1_RX`) |
| RX (`Serial1`) | PA9 (`USART1_TX`) |
| GND | GND |

Монитор порта — `Serial` 115200.

## Что делает скетч

1. Ждёт ответ на `Ping`.
2. Включает режим `Normal`.
3. На Payload5v ставит OC 1 А и UV 90%, затем включает канал.
4. Раз в секунду печатает состояние, напряжение и ток всех шести каналов.
5. Символ `b` в мониторе порта переводит плату в загрузчик.
