Подробное описание

Базовый класс для устройств, использующих AT-команды

Класс ATDevice наследуется от UARTDevice и предоставляет функциональность для формирования и выполнения AT-команд. Поддерживает шаблонные методы для работы с различным количеством параметров команд.
