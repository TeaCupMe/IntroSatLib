Подробное описание

Класс для управления LoRa модулем E32-433.

Реализует функционал работы с трансивером E32-433 через UART интерфейс. Позволяет настраивать параметры, передавать и принимать данные.

◆ AddressingMode

enum class IntroSatLib::E32_433::AddressingMode : uint8_t
strong

Перечисление режимов адресации

Определяет способ адресации при передаче:

  • Transparent: прозрачный режим (все пакеты принимаются)
  • Fixed: фиксированная адресация (только адресные пакеты)

◆ CommandHead

enum class IntroSatLib::E32_433::CommandHead : uint8_t
strong

Заголовки команд для работы с регистрами

Определяет коды команд для взаимодействия с модулем:

  • SetParametersSave: установка параметров с сохранением
  • GetParameters: чтение параметров
  • SetParametersNoSave: установка параметров без сохранения
  • GetVersion: чтение версии прошивки
  • Reset: программный сброс модуля

Перечисление режимов работы модуля

Определяет доступные режимы работы E32-433:

  • Normal: нормальный режим (M0=0, M1=0)
  • Wakeup: режим пробуждения (M0=1, M1=0)
  • PowerSave: энергосберегающий режим (M0=0, M1=1)
  • Sleep: спящий режим (M0=1, M1=1)

Структура настроек модуля E32-433.

Содержит параметры конфигурации модуля размером 6 байт:

  • head: заголовок команды (0xC0 для установки параметров)
  • addr: адрес модуля (16 бит)
  • sped: настройки скорости UART и эфира
  • chan: номер канала (0x00-0x1F)
  • option: дополнительные опции (режим адресации, вывод, FEC, мощность)
