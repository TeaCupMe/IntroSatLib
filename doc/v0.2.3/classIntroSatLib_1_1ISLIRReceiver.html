Подробное описание

Приёмник ИК-сигналов, работающий по прерываниям.

Класс реализует конечный автомат для декодирования ИК-посылок на основе временных параметров протокола. Ожидается вызов ProcessReceiving() в обработчике прерывания по изменению уровня на входном пине.
